# Private-workspace presentation

This public UI contains presentation code and high-level technology descriptions only. Request collections and MT/MX messages are loaded by an operator from the corresponding private core's workbench/workspace.private.json, and remain in page memory. There are no collection/message export or download controls. Reset/reload removes the private view.

Do not put the private workspace file inside this public docs tree. Anything rendered is visible to the authorized viewer and can be copied; this is not DRM. Use restricted access and approved records for a shared session.

Reference replay is clearly distinct from network execution. Business MT/MX context is not a replacement for REST/JSON or MCP/JSON-RPC framing. Model/provider execution, source completeness and scheme conformance must be assessed separately. MCP playbooks describe useful evidence/tool sequences; no measured superiority over equivalent APIs is claimed.

Live calls still require the existing private core, approved gateway routes, correct credentials and exact allowed browser origin. No deployment, publication or access-control integration was added by this UI change.

## Knowledge Graph

Load the authorized private workspace, then open Knowledge Graph to browse its source occurrences and cited relationships. Search a reference/name/code, choose a starting node and relationship depth, and inspect the evidence or table. This is snapshot graph-guided retrieval; no model answer is generated. Unloading clears the graph. Graph data and projection rules stay in the private core.

## Source-quoted graph answers

The graph tab can call a separately authenticated private graph API. Prepare a local answer first. Optional Gemini selection requires an enabled private service, a fresh sharing preview and explicit approval. The REST envelope and actual response are inspectable in the panel. No provider key enters the browser. Quotes and citations are checked against the loaded snapshot.

## Observed API activity

Configure the private graph connection and opt into capture in the graph tab. Completed live REST/MCP/upload responses then update its in-memory graph. Reference replays are excluded. Dashed links show browser-reported observations with source receipt time; they are not independent backend history. New local answers can cite these records. Observed contexts are excluded from Gemini sharing. Retention is bounded and resets on service restart.
